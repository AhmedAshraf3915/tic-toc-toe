# Tic-Tac-Toe

A simple tic-tac-toe game built with React and Vite.

## Features

- Two-player tic-tac-toe gameplay
- Editable player names
- Active-player indicator
- Win and draw detection
- Move history
- Restart game support

## Technologies

- React
- Vite
- JavaScript
- CSS

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Create a production build
- `npm run preview` - Preview the production build
- `npm run lint` - Check the code with ESLint

## How to Play

1. Enter names for both players.
2. Player X starts the game.
3. Players take turns selecting an empty square.
4. The first player to complete a row, column, or diagonal wins.
5. If all squares are filled without a winner, the game ends in a draw.
